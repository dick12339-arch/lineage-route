安裝「天堂路線」書籤

把下面的金色按鈕拖曳到瀏覽器的書籤列，就安裝完成。

⚔ 天堂路線

方法一：拖曳安裝（電腦版 Chrome / Edge / Firefox）

  1. 按 Ctrl+Shift+B（Mac 為 ⌘+Shift+B）顯示書籤列。
  2. 用滑鼠按住上方金色「⚔ 天堂路線」按鈕。
  3. 拖到書籤列上放開。
  4. 到任何一般網頁（例如 google.com），點書籤列上的「天堂路線」，路線視窗就會出現。
  5. 手機豎版：視窗貼在畫面底部，按住標題列上下拖就能調高度，最小只剩選單和「當前這一步」，用 ◀ ▶ 切換步驟。
  6. 標題列按鈕：「小／中／大」切換大小、「透明」讓視窗半透明並可點到後面畫面、「—」收合成 ⚔ 按鈕、「✕」關閉。
  7. 電腦橫版：按住標題列可移動視窗，拖曳右下角可調整大小；⚔ 按鈕也能拖曳，位置會記住。

方法二：手機（Android Chrome）

  1. 按下面的「複製書籤代碼」。
  2. 在這個頁面按右上角「⋮」→ 點「☆」把本頁加入書籤。
  3. 再按「⋮」→「書籤」→ 找到剛加入的書籤，按它右邊的「⋮」→「編輯」。
  4. 名稱改成「天堂路線」；網址欄位全部刪掉，長按 →「貼上」剛複製的代碼。
  5. 按左上角「←」儲存。
  6. 使用時：打開任一網頁 → 點網址列 → 輸入「天堂路線」→ 從下拉清單點有星號的那筆書籤。

方法三：iPhone（Safari）

  1. 按下面的「複製書籤代碼」。
  2. 按下方「分享」鈕 →「加入書籤」→ 儲存。
  3. 按「書籤」鈕（打開的書本圖示）→ 右下「編輯」→ 點剛加入的書籤。
  4. 名稱改成「天堂路線」；網址欄位清空後貼上代碼，按「完成」。
  5. 使用時：打開任一網頁 → 書籤 → 點「天堂路線」。

樂園橫版書籤（讓遊戲在電腦上變橫的）

  1. 按下面的「複製樂園橫版代碼」。
  2. 在書籤工具列的「樂園橫版」上按右鍵 →「編輯書籤…」（沒有的話就在空白處按右鍵 →「新增書籤…」，名稱填「樂園橫版」）。
  3. 「網址」欄位全部刪掉，貼上剛複製的代碼，按「儲存」。
  4. 進入遊戲畫面後點「樂園橫版」，左下角會出現金框控制列，顯示「橫版 ○○○×1280」就成功了。

版本：樂園橫版 v1.0（2026-11-04）

最穩定的用法：一般書籤

直接把完整網頁版存成一般書籤，任何瀏覽器都能用：
dick12339-arch.github.io/lineage-route

注意

  1. 書籤要在「已開啟的網頁」上點才會動作；空白新分頁、瀏覽器設定頁不能執行。
  2. 少數網站（例如 Google 搜尋首頁、GitHub）禁止載入外部程式，會跳出「天堂路線載入失敗」，換到一般網頁（例如新聞網站）再點，或改用上面的一般書籤。
  3. 程式放在網路上，之後更新不用重裝書籤，點下去就是最新版。
