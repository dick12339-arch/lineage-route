# 天堂路線（天堂1 亞丁大陸路線指引）

- 完整網頁版：https://dick12339-arch.github.io/lineage-route/
- 安裝書籤：https://dick12339-arch.github.io/lineage-route/install.html
- 書籤主程式：`l1.js`（經 jsDelivr 載入：https://cdn.jsdelivr.net/gh/dick12339-arch/lineage-route@main/l1.js）（書籤只是一行啟動碼，點擊時載入這支程式）

怪物與掉落資料取自「樂園 怪物查詢」https://joelbutaladr.github.io/linwebtw/

地圖圖片由 https://www.lcinfo.io/maps 於執行時載入，本儲存庫不含任何地圖檔。

版本資訊：v1.8（2026-10-28）— 改用 lcinfo.io 真實地圖（執行時讀取，不存放於本儲存庫）、雙指縮放拖曳、輸入 /loc 標示我的位置；v1.7 怪物導航自動顯示地圖。
